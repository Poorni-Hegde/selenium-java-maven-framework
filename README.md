# Selenium Java Maven Framework

## Overview
This project is a Selenium Automation Framework developed using Java, Selenium WebDriver, Maven and TestNG.

## Technologies Used
- Java
- Selenium WebDriver
- Maven
- TestNG
- Page Object Model (POM)

## Test Scenarios Automated
- Valid Login
- Invalid Login
- Add Product To Cart

## Website Tested
https://www.saucedemo.com

## Project Structure

src/test/java
├── base
├── pages
├── tests
└── utils
